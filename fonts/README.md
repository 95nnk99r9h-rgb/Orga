# Schriften

Mitgeliefert (nicht von Google geladen), damit die App offline funktioniert und keine Daten an Dritte gehen. Je eine variable WOFF2-Datei, Zeichensatz Latin.

| Datei | Schrift | Verwendung | Lizenz |
|---|---|---|---|
| `bricolage-grotesque.woff2` | Bricolage Grotesque (Achsen: Strichstärke, optische Größe) | Überschriften | SIL Open Font License 1.1 – `OFL-bricolage-grotesque.txt` |
| `figtree.woff2` | Figtree | Fließtext | SIL Open Font License 1.1 – `OFL-figtree.txt` |
| `jetbrains-mono.woff2` | JetBrains Mono | Nummern, Platz-Codes | SIL Open Font License 1.1 – `OFL-jetbrains-mono.txt` |

Quelle: Fontsource-Pakete `@fontsource-variable/*` 5.3.0.
