# Das Fundort-System – Lager-Handbuch für die Apotheke

Zum Ausdrucken und an die Lagertür hängen. Die gleichen Inhalte stehen in der App unter *Mehr → Das Fundort-System*.

> **Wofür Fundort da ist – und wofür nicht:** Fundort zeigt, *wo* etwas im Lager steht und was bald abläuft. Bestände, Bestellungen, BtM-Dokumentation und Temperaturprotokolle bleiben in der Warenwirtschaft und den vorgeschriebenen Systemen. **Keine Patientendaten** in Fundort eintragen.

---

## Die vier Regeln

### 1. Jeder Boden hat eine Adresse

- Regale bekommen **Buchstaben**: A, B, C … – links neben der Tür beginnend, einmal rundherum.
- Böden bekommen **Zahlen**: 1, 2, 3 … – **von oben nach unten**.
- **Jedes Regal hat so viele Böden, wie es eben hat.** Ein hohes Regal mit sechs Böden hat B1–B6, ein schmales mit vier C1–C4.
- Die Adresse ist Buchstabe + Zahl: **„B3“ = Regal B, dritter Boden von oben.**

```
                 Tür
                  │
   ┌──────────────┴──────────────┐
   │ S1 Kühlschrank              │
 A │                             │ C
   │        S3 (Boden vor B)     │
   │                             │      S2 = Sperrlager
   └──────────── B ──────────────┘      S4 = Keller

   Regal A      Regal B      Regal C
   ┌──────┐     ┌──────┐     ┌──────┐
   │ A1   │     │ B1   │     │ C1   │  ← oben
   │ A2   │     │ B2   │     │ C2   │
   │ A3   │     │ B3   │     │ C3   │
   │ A4   │     │ B4   │     │ C4   │
   │ A5   │     │ B5   │     └──────┘
   └──────┘     │ B6   │     4 Böden
   5 Böden      └──────┘
                6 Böden
```

Jeder Boden bekommt ein **Boden-Etikett** mittig an die Vorderkante (in der App: *Etiketten → Regale & Plätze*). Optional ein großes **Regal-Schild** oben ans Regal.

### 2. Was nicht ins Regal gehört, bekommt einen Stellplatz

- Feste Plätze außerhalb der Regale heißen **S1, S2, S3 …** und haben einen Namen: „Kühlschrank (2–8 °C)“, „Sperrlager“, „Boden vor Regal B“.
- Auch Orte **außerhalb des Lagers** können Stellplätze sein: „Keller“, „Büro“, „Rezeptur“.
- Ein **Stellplatz-Etikett** kommt an die Tür, die Wand oder auf den Boden daneben – so lässt sich dort genauso einlagern wie im Regal.

### 3. Alles bekommt eine Nummer

- **Kisten** und **Einzelstücke** ohne Kiste (Rollator, Aufsteller, Leihgeräte wie Milchpumpen oder Babywaagen) bekommen eine fortlaufende Nummer **001, 002, 003 …** – beide aus derselben Reihe.
- Die Nummer bleibt, auch wenn etwas umzieht oder sich der Inhalt ändert.
- Aufs Etikett kommen **nur Nummer, Kategorie-Farbe und QR-Code** – **kein Inhalt, kein Verfall**. So muss nie neu beschriftet werden.
- Bei Kisten auf die **Stirnseite**, die man im Regal sieht. Bei Einzelstücken gut sichtbar aufkleben oder als **Anhänger** (kleines Etikett, gelocht, mit Kabelbinder).

### 4. Die App merkt sich den Rest

- Zu jeder Kiste: die **Artikel** (gern mit Stärke, Packungsgröße, Anzahl oder PZN), der **früheste Verfall**, **Kategorie**, **Platz** und ein **Foto**.
- Zu jedem Einzelstück: ein **Titel** (z. B. „Milchpumpe · Leihgerät 2“), **Kategorie**, **Platz** und ein Foto.
- Gesucht wird in der App: „Ibuprofen“ oder eine PZN eintippen → „Kiste 001 · A1“.

---

## Verfall im Blick

- Beim Einlagern den **frühesten Verfall** der Kiste eintragen (Feld „Verfall“, z. B. `03/2027`).
- Im Lager erscheint oben **„Verfall prüfen“**, sobald etwas abgelaufen ist oder in der Vorwarnzeit liegt. Die Vorwarnzeit (1, 3, 6 oder 12 Monate) stellt ihr unter *Mehr → Verfall-Warnung* für das ganze Team ein.
- **Monatliche Verfallskontrolle:** „Verfall“ öffnen, Kurzläufer vorziehen oder abverkaufen, Retouren anmelden, Abgelaufenes aussondern – und in der App den Verfall aktualisieren oder die Kiste umlagern.
- **First Expired, First Out:** Was zuerst abläuft, steht vorn.

## Der Einrichtungstag – Checkliste

Rechne mit **1–2 Minuten pro Stück**. Zu zweit geht es doppelt so schnell: eine Person räumt, eine tippt. Gut für einen ruhigen Nachmittag oder nach Ladenschluss.

**Vorbereitung**

- [ ] App auf den Geräten installieren, Regale mit ihrer jeweiligen Bodenzahl und die Stellplätze einrichten (*Mehr → Lagerorte*)
- [ ] Jedem Regal eine Ortsbeschreibung geben („links neben der Tür“)
- [ ] Boden- und Stellplatz-Etiketten drucken und anbringen
- [ ] Nummern-Etiketten vorab drucken (z. B. 001–024, *Etiketten → Nummern → Neue Nummern*)
- [ ] Eine Kiste für Retouren und eine für die Entsorgung bereitstellen

**Pro Kiste oder Einzelstück**

1. Herausnehmen, kurz durchsehen – Abgelaufenes oder Beschädigtes direkt aussondern.
2. Nächstes Nummern-Etikett anbringen.
3. In der App **Scannen** → Etikett scannen → **Kiste** oder **Einzelstück** tippen.
4. Artikel und frühesten Verfall eintippen (bei Einzelstücken einen Titel), Kategorie wählen, Foto machen. Sichern.
5. Ins Regal oder auf den Stellplatz stellen und dessen **Etikett scannen** → eingelagert.

**Zum Schluss**

- [ ] *Mehr → Backup erstellen* und das Backup sicher ablegen
- [ ] Retouren und Entsorgung noch am selben Tag auf den Weg bringen

## Gute Gewohnheiten

| | Gewohnheit | So geht’s |
|---|---|---|
| 📅 | **Verfall beim Einlagern eintragen** | Bei gemischten Kisten zählt der früheste Artikel |
| 🔄 | **Monatliche Verfallskontrolle** | „Verfall“ öffnen: vorziehen, abverkaufen, retournieren oder aussondern |
| 👀 | **Kurzläufer nach vorn** | Was zuerst abläuft, steht vorne (First Expired, First Out) |
| ⚠️ | **Sperrware klar trennen** | Retouren, Rückrufe und Beanstandungen auf den Stellplatz „Sperrlager“ |
| ↕️ | **Raus = austragen** | Kiste in die Offizin geholt oder Gerät verliehen → „Nicht im Lager“. Zurück: Nummer + Platz scannen |
| ⚖️ | **Schweres nach unten** | Flüssigkeiten, Großpackungen und schwere Kartons auf die unteren Böden |
| 🏷️ | **Etikett zum Gang** | Immer auf die sichtbare Seite, bei Stapeln auf jede Kiste |
| ✋ | **Keine Patientendaten** | Leihgeräte nur mit der Leihschein-Nummer aus der Warenwirtschaft, nie mit Namen |
| 👥 | **Das ganze Team macht mit** | Jeder weiß: raus → austragen, rein → scannen |

## Kategorien und Farben (Vorschlag)

| Farbe | Kategorie | Typischer Inhalt |
|---|---|---|
| 🔵 Blau | Überbestand | Großpackungen, Mehrfachbestellungen, Nachschub für die Sichtwahl |
| 🟠 Orange | Aktion & Saison | Sonnenschutz, Erkältung, Herbstaktion |
| 🩷 Pink | Kosmetik & Pflege | Pflegeserien, Proben |
| 🌿 Mint | Verbandstoffe | Binden, Kompressen, Pflaster |
| 🩵 Türkis | Hilfsmittel | Bandagen, Kompressionsmuster, Rollator |
| 🟣 Indigo | Leihgeräte | Milchpumpen, Babywaagen, Inhaliergeräte |
| 🟪 Lila | Rezepturbedarf | Kruken, Tuben, Grundlagen |
| 🟤 Braun | Verbrauchsmaterial | Tüten, Kassenrollen, Etiketten |
| 🟡 Gelb | Werbemittel & Deko | Schaufensterdeko, Aufsteller, Plakate |
| 🔴 Rot | Retouren & Sperrware | Retouren, Rückrufe, Beanstandungen |
| ⚪ Grau | Büro & Archiv | Ordner, Lieferscheine, Prüfprotokolle |

Die Farbe wird als Streifen aufs Etikett gedruckt. Wer schwarz-weiß druckt, klebt farbige Klebepunkte dazu. Kategorien und Farben lassen sich in der App frei ändern.

---

## Material

- Stapelbare Kisten oder Wannen, möglichst ein bis zwei Größen
- Drucker und Papier – oder Universal-Etiketten **105 × 74 mm** (8 pro A4) bzw. **70 × 37 mm** (24 pro A4)
- Breites transparentes Klebeband oder Klebefolie, alternativ selbstklebende Etikettentaschen
- Locher und Kabelbinder für Anhänger an Einzelstücken
- Optional: farbige Klebepunkte (Ø 19 mm) für die Kategorien
