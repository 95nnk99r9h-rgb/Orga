# Das Fundort-System – Keller-Handbuch

Zum Ausdrucken und an die Kellertür hängen. Die gleichen Inhalte stehen in der App unter *Mehr → Das Fundort-System*.

---

## Die vier Regeln

### 1. Jeder Boden hat eine Adresse

- Regale bekommen **Buchstaben**: A, B, C … – links neben der Tür beginnend, einmal rundherum.
- Böden bekommen **Zahlen**: 1, 2, 3 … – **von oben nach unten**.
- **Jedes Regal hat so viele Böden, wie es eben hat.** Ein hohes Regal mit drei Fächern hat B1–B3, ein schmales mit sechs D1–D6.
- Die Adresse ist Buchstabe + Zahl: **„B3“ = Regal B, dritter Boden von oben.**

```
                 Tür
                  │
   ┌──────────────┴──────────────┐
   │ S3 (Wandhaken)              │
 A │                             │ D
   │        S1 (Boden vor C)     │
   │                             │      S2 = Unter der Treppe
   └──── B ──────────── C ───────┘

   Regal A      Regal B      Regal C      Regal D
   ┌──────┐     ┌──────┐     ┌──────┐     ┌──────┐
   │ A1   │     │      │     │ C1   │     │ D1   │  ← oben
   │ A2   │     │ B1   │     │ C2   │     │ D2   │
   │ A3   │     │      │     │ C3   │     │ D3   │
   │ A4   │     │ B2   │     │ C4   │     │ D4   │
   │ A5   │     │ B3   │     └──────┘     │ D5   │
   └──────┘     └──────┘                  │ D6   │  ← unten
   5 Böden      3 hohe Böden  4 Böden     └──────┘
                                          6 Böden
```

Jeder Boden bekommt ein **Boden-Etikett** mittig an die Vorderkante (in der App: *Etiketten → Regale & Plätze*). Optional ein großes **Regal-Schild** oben ans Regal.

### 2. Was nicht ins Regal passt, bekommt einen Stellplatz

- Feste Plätze außerhalb der Regale heißen **S1, S2, S3 …** und haben einen Namen: „Unter der Treppe“, „Boden vor Regal C“, „Wandhaken“.
- Weitere Räume wie **Dachboden** oder **Garage** bekommen in der App einen eigenen Bereich mit eigenen Regalen und Stellplätzen (*Mehr → Lagerorte → Raum hinzufügen*). Die Buchstaben zählen einfach weiter: Hat der Keller A–D, beginnt die Garage mit E.
- Ein **Stellplatz-Etikett** kommt an die Wand oder auf den Boden daneben – so lässt sich dort genauso einlagern wie im Regal.

### 3. Alles bekommt eine Nummer

- **Kisten** und **große Einzelstücke** ohne Kiste (Weihnachtsbaum, Koffer, Kinderwagen, Schlitten) bekommen eine fortlaufende Nummer **001, 002, 003 …** – beide aus derselben Reihe.
- Die Nummer bleibt, auch wenn etwas umzieht oder sich der Inhalt ändert.
- Aufs Etikett kommen **nur Nummer, Kategorie-Farbe und QR-Code** – **kein Inhalt**. So muss nie neu beschriftet werden.
- Bei Kisten auf die **Stirnseite**, die man im Regal sieht. Bei Einzelstücken gut sichtbar aufkleben oder als **Anhänger** (kleines Etikett, gelocht, mit Kabelbinder).

### 4. Die App merkt sich den Rest

- Zu jeder Kiste: **ein Foto**, **3–10 Stichworte zum Inhalt**, **Kategorie** und **Platz**.
- Zu jedem Einzelstück: **ein Foto**, **ein Titel** (z. B. „Weihnachtsbaum“), **Kategorie** und **Platz**.
- Gesucht wird in der App: „Lichterkette“ eintippen → „Kiste 002 · A1“.

## Der Einräum-Tag – Checkliste

Rechne mit **1–2 Minuten pro Stück**. Zu zweit geht es doppelt so schnell: eine Person räumt, eine tippt.

**Vorbereitung**

- [ ] App auf dem Handy installieren, Regale mit ihrer jeweiligen Bodenzahl und die Stellplätze einrichten (*Mehr → Lagerorte*)
- [ ] Jedem Regal eine Ortsbeschreibung geben („links neben der Tür“)
- [ ] Boden- und Stellplatz-Etiketten drucken und anbringen
- [ ] Nummern-Etiketten vorab drucken (z. B. 001–024, *Etiketten → Nummern → Neue Nummern*)
- [ ] Eine leere Kiste „Spenden“ und eine „Weg“ bereitstellen

**Pro Kiste oder Einzelstück**

1. Herausnehmen, öffnen, kurz durchsehen – Aussortiertes direkt in „Spenden“ oder „Weg“.
2. Nächstes Nummern-Etikett anbringen.
3. In der App **Scannen** → Etikett scannen → **Kiste** oder **Einzelstück** tippen.
4. Foto, Kategorie und – bei Kisten – Stichworte zum Inhalt, bei Einzelstücken ein Titel. Sichern.
5. Ins Regal oder auf den Stellplatz stellen und dessen **Etikett scannen** → eingelagert. Mehrere für denselben Boden: erst alle Nummern scannen, dann einmal den Boden.

**Zum Schluss**

- [ ] *Mehr → Backup erstellen* und das Backup z. B. in iCloud Drive sichern
- [ ] Spenden- und Weg-Kiste noch am selben Tag aus dem Keller bringen

## Gute Gewohnheiten

| | Gewohnheit | So geht’s |
|---|---|---|
| ⚖️ | **Schweres nach unten** | Werkzeug, Dokumente, Bücher auf die unteren Böden, Leichtes nach oben |
| 👀 | **Häufiges auf Augenhöhe** | Was oft gebraucht wird: mittlere Böden, vorne |
| 🧳 | **Großes an feste Stellplätze** | Weihnachtsbaum, Koffer & Co. bekommen einen eigenen Stellplatz, statt im Weg zu stehen. Hohe Teile passen oft auf den untersten Boden |
| 📅 | **Saisonal tauschen** | Herbst: Weihnachten nach vorne. Frühjahr: Ostern und Garten |
| ↕️ | **Raus = austragen** | Etwas mit nach oben genommen → in der App „Entnommen“. Zurück: Nummer + Platz scannen |
| 🏷️ | **Etikett zum Gang** | Immer auf die sichtbare Seite, bei Stapeln auf jede Kiste |
| 📦 | **Gleiche Kisten** | Stapelbare Boxen mit Deckel (45–60 l) schützen vor Staub und Feuchtigkeit |
| 🔄 | **Einmal im Jahr Keller-Check** | Alles „Ohne Platz“ auflösen, Inhalte prüfen, Unbenutztes aussortieren |
| 📄 | **Liste an die Tür** | *Etiketten → Listen*: eine Inhaltsliste pro Regal – für alle, die ohne Handy suchen |
| 👨‍👩‍👧 | **Alle machen mit** | Jeder weiß: raus → austragen, rein → scannen |

**Faustregel fürs Aussortieren:** Was beim Keller-Check zwei Jahre lang nicht gebraucht wurde und keinen Erinnerungswert hat, darf gehen.

## Kategorien und Farben (Vorschlag)

| Farbe | Kategorie | Typischer Inhalt |
|---|---|---|
| 🔴 Rot | Weihnachten | Baumschmuck, Lichterketten, Krippe, künstlicher Baum |
| 🟠 Orange | Deko | Ostern, Halloween, Tischdeko |
| 🔵 Blau | Kleidung | Winter-/Sommersachen, Babykleidung |
| 🩷 Pink | Kinder & Spielzeug | Lego, Puppen, Kinderwagen |
| 🟢 Grün | Sport & Camping | Zelt, Skiausrüstung, Koffer, Schlitten |
| 🟤 Braun | Werkzeug | Bohrmaschine, Schrauben, Malerbedarf |
| 🟣 Indigo | Elektronik & Kabel | Ladegeräte, alte Handys, Kabel |
| 🩵 Türkis | Küche & Haushalt | Partygeschirr, Raclette, Geschenkpapier |
| ⚪ Grau | Dokumente | Ordner, Verträge, Steuer |
| 🟪 Lila | Erinnerungen | Fotoalben, Kinderzeichnungen |

Die Farbe wird als Streifen aufs Etikett gedruckt. Wer schwarz-weiß druckt, klebt farbige Klebepunkte dazu. Kategorien und Farben lassen sich in der App frei ändern.

## Material

- Stapelbare Kisten mit Deckel, möglichst ein bis zwei Größen
- Drucker und Papier – oder Universal-Etiketten **105 × 74 mm** (8 pro A4) bzw. **70 × 37 mm** (24 pro A4)
- Breites transparentes Klebeband oder Klebefolie, alternativ selbstklebende Etikettentaschen
- Locher und Kabelbinder für Anhänger an Einzelstücken
- Optional: farbige Klebepunkte (Ø 19 mm) für die Kategorien
